# Meu Site Pessoal

**Nome do Aluno:** [Gabriel Pavan Wesling]

## Objetivo da Atividade
Desenvolver um site pessoal de forma incremental (HTML -> CSS -> Responsividade), aplicando os conceitos estudados em aula. O foco principal é separar corretamente a estrutura da apresentação, garantir a semântica do código HTML5 e aplicar a metodologia **Mobile First** usando CSS puro (Flexbox, Grid e Media Queries).

## Etapas Cumpridas:
- [x] Estruturação base em HTML semântico.
- [x] Adição de links, imagens e formulário de contato.
- [x] Estilização com CSS externo (Cores, tipografia, hover states).
- [x] Configuração da tag meta viewport.
- [x] Adaptação do Layout via Mobile First.
- [x] Responsividade para 3 breakpoints principais (Mobile, Tablet, Desktop) via Media Queries.
